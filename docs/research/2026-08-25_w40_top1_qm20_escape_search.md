# W40 Defender五日后Top1质量动量逃生研究

日期：2026-08-25  
证据状态：固定当前正式策略的预注册回溯搜索，不是独立样本外  
结论：机制被否证，不修改生产

## 1. 固定机制

基础策略固定为`momentum_defender_w40_reversal_full_equity_v1`，不修改W40窗口、55%/40%、
1/1确认、30/30锁、月度40日最弱红利选择或100%红利仓位。

新增覆盖层严格按以下规则运行：

1. 实际策略连续持有Defender满5个交易日后，才允许检查逃生；
2. 当前Momentum Top1 ETF和连续持有正式Defender净值都调用注册的
   `quality_momentum 2.0.0`：20日对数收益乘对数路径效率；
3. 若`QM20(Top1) - QM20(Defender) > X`，下一开盘可打破Defender 30日锁；
4. 入场Top1固定持有5个完整交易日，即使期间Top1改变或基础W40恢复，也不提前退出；
5. 第6个开盘起，若基础W40仍为Defender且差值`<Y`，返回Defender；否则交还现有Momentum
   的正常Top1轮转，其原5日持有过滤继续生效；
6. 返回Defender后重新累计5个实际Defender交易日，不能立即再次逃生。

所有指标只使用上一收盘及更早数据，下一开盘执行；切换复合旧袖套退出腿和新袖套进入腿。

## 4. 参数稳定性

X=0.06、Y=0.02的9点相邻网格：

- 年化Q25 47.73%，Sharpe Q25 1.589；
- 年化差Q25 -2.77个百分点，Sharpe差Q25 -0.086；
- 邻域内年化和Sharpe同时提高的比例为0。

全样本、去极端排序和联合排序虽然都选到同一回退点，但这是“最少退化”的一致，不是正向稳健
平台。

## 5. 为什么失败

稳健代表11次逃生中7正4负，但4次负事件幅度更大：

- 2020-05-06纳指逃生：候选-4.19%，Defender约-0.44%，log差-3.84%；
- 2022-08-12纳指逃生：候选+1.08%，Defender+5.36%，log差-4.14%；
- 2025-04-17黄金逃生：候选-1.68%，Defender-0.65%，log差-1.05%；
- 2025-05-09创业板逃生：候选+0.33%，Defender+4.34%，log差-3.91%。

QM20差值识别的是Top1相对过去20日更强，不保证未来5日继续更强。强制5日持有把部分短期
领先变成追涨；同时正式Defender恰好采用40日最弱反转，二者经常处于“趋势延续”与“均值回归”
的相反端。2019年该机制贡献+7.07个百分点，但2020年-4.10、2022年-1.63、2025年-5.67，
收益高度依赖时期，无法稳定外推。

## 6. 过拟合与压力测试

- 当前族Reality Check：完整`p=0.9898`、普通区间`p=0.9964`；
- 合并当前正式策略仓位研究后共284条唯一收益路径，全局Reality Check均为`p=1.000`；
- 当前族CSCV-PBO完整5.84%、普通0.65%，但训练选择在测试块击败正式基线的比例仅
  1.95%/1.52%，说明候选之间可排序，却普遍不如基线；
- 全局CSCV-PBO 63.85%；
- walk-forward年化/Sharpe胜率20%/20%；leave-one-year为25%/12.5%；
- Bootstrap年化差95%区间[-4.50, +3.37]个百分点，Sharpe差[-0.145, +0.079]；
- 三倍费用下降至48.63%年化、1.617 Sharpe。

## 7. 决策

1. 当前正式`momentum_defender_w40_reversal_full_equity_v1`保持不变；
2. X=0.06、Y=0.02只作为“最少退化”审计代表，不进入策略配置或默认日跑；
3. 不在同一历史上继续移动X/Y网格，也不增加资产专用阈值；
4. 该机制的失败说明20日质量动量相对优势不适合直接打破30日Defender锁并强制持有5日。
