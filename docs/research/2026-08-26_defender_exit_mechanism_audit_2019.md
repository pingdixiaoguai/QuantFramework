## 1. 当前机制

当前W40只观察510300。进入Defender后，恢复条件是上一收盘的40日下跌幅度分位

\[
P_t^{(40)}\le 0.40.
\]

但即使恢复条件已经满足，只要Defender尚未持有30个完整交易日，状态仍保持Defender。简写为：

\[
\text{ExitDefender}_{t+1}
=
\mathbf 1\!\left(d_t^D\ge 30\right)
\mathbf 1\!\left(P_t^{(40)}\le0.40\right),
\]

其中\(d_t^D\)是下一开盘前已经完成的Defender持有日数。黄金逃生是独立覆盖层，不改写这个
基础状态及其计数。

## 2. 30日锁的优点

### 2.1 防止把一次性反弹当成状态恢复

当前恢复分数来自

\[
L_t^{(40)}=\max\!\left(-\ln(C_t/C_{t-40}),0\right).
\]

只要40日收益转正，\(L_t^{(40)}\)及其分位就直接变成0。这个指标在恢复侧具有很大的0点质量，
一次短促反弹就可能从高风险分位跳到0；若没有锁，策略很容易立即切回Momentum。

### 2.2 历史上显著降低来回切换

2019重启样本的固定锁曲线为：

|0日|39.64%|1.363|-25.92%|27|
|5日|45.99%|1.540|-25.50%|25|
|10日|47.58%|1.598|-25.50%|22|
|15日|48.09%|1.622|-25.50%|22|

0日至30日总体呈近似单调改善，说明锁的历史贡献不是简单由一个偶然交易日制造。

### 2.3 锁的正贡献分布在多段事件

20次基础Defender进入中，16段在锁内已经出现恢复信号，共154个“恢复满足但被锁阻塞”的
交易日。逐段把第一次锁内恢复改成提前释放后，原30日锁相对有利11段、不利5段；前两大正
贡献只占全部正向锁贡献43.0%。因此“恰好踩中唯一一次上涨”并不成立，收益来自多次阻止过早
退出。

## 3. 30日锁的缺点

### 3.1 时间是唯一变量，完全忽略恢复强度

第29日无论恢复多强都不能退出，第30日即使只是临界恢复也可以退出，存在人为不连续点。
2019-01、2019-11、2020-09、2024-12和2026-07等事件中，提前释放反而优于继续锁定，说明
机会成本真实存在。

### 3.2 当前退出指标无法区分“微弱转正”和“强劲恢复”

由于所有正40日收益都映射成\(P=0\)，把早退阈值从0%、10%、20%调到30%经常产生同一条路径。
这意味着不能只靠移动当前恢复分位阈值获得真正的灵活性；需要把进入和退出指标解耦。

### 3.3 30日确实是历史局部峰

向更长锁扩展后：35日为52.59%/1.755，40日为45.31%/1.561，50日为41.01%/1.460。
因此30日不是一个宽平台，而是25–35日之间的历史局部峰。它的方向性价值较可信，但精确的
“30”仍有参数拟合风险。

## 4. 测试过的灵活退出机制

其他层全部冻结，共测试两轮：

1. 固定0–30日短锁；5/10日最短锁＋2/3/5/10日连续恢复确认；强恢复早退；线性放宽恢复线；
2. 进入继续使用下跌分位，退出改用有符号10/20/40/60日收益、Momentum相对Defender QM20，
   以及两者交集，全部使用自然零阈值和连续确认。

第一轮44个参数ID去重为21条路径，第二轮24条路径。没有任何灵活候选同时超过当前完整年化和
Sharpe。

## 5. 最优低维替代机制

机制上最整洁、历史退化最小的是：

1. Defender至少持有5个完整交易日；
2. 计算510300的有符号40日对数收益

   \[
   R_t^{(40)}=\ln(C_t/C_{t-40});
   \]

3. 若\(R_t^{(40)}>0\)连续10个收盘，则下一开盘提前退出Defender；
4. 若没有提前退出，第30日以后仍沿用当前\(P_t^{(40)}\le0.40\)单日恢复规则。

令

\[
S_t=
\begin{cases}
S_{t-1}+1,&R_t^{(40)}>0,\\
0,&R_t^{(40)}\le0,
\end{cases}
\]

则早退条件为

\[
d_t^D\ge5\quad\land\quad S_t\ge10.
\]

这个规则把“最低观察期”“恢复方向”和“持续性”分开，比单一30日硬锁更容易解释，而且阈值0
具有自然经济含义。它与“P40≤0.40连续10日”的早退候选在当前历史上产生同一路径，只提前退出
2次。

|方案|年化|Sharpe|MDD|最弱分段Sharpe|
|---|---:|---:|---:|---:|
|当前30日锁|56.82%|1.854|-25.50%|1.766|
|5日最短＋R40转正连续10日＋30日fallback|57.03%|1.844|-25.50%|1.766|

候选提高0.21个百分点年化，但Sharpe下降0.010，未完成双目标。20日Bootstrap年化差区间
[-2.98%, +4.78%]、Sharpe差区间[-0.090, +0.072]；有符号恢复族Reality Check
`p=0.8824`，walk-forward和留一年重选的双指标胜率均为0。费用不是问题，时间稳定性才是问题。

## 6. 结论与建议

1. **30日锁不够灵活的判断成立。** 它忽略恢复强度，154个交易日出现“已经恢复但仍等待”。
2. **收益并非只来自一次幸运上涨。** 11段受益、5段受损，前两大正贡献占43%；锁的方向性作用
   有重复证据。
3. **精确30日仍有拟合风险。** 30日在25–35日之间是明显局部峰，不宜宣称为普适最优参数。
4. **更优雅的结构是非对称状态机：风险分位负责进入，有符号恢复＋连续确认负责提前退出，30日
   只作为fallback。** 但当前历史不支持直接替换生产。
5. 建议把“5日最低持有＋R40转正连续10日＋30日fallback”冻结为只读前瞻影子。不要继续在
   同一历史上搜索9日、11日或其他收益阈值；等新Defender事件积累后再比较。
