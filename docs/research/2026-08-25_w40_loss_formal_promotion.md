# 单一W40下跌幅度分位正式策略晋升

日期：2026-08-25  
正式策略：`momentum_defender_w40_loss_excluding_extremes_v1`  
晋升权限：用户明确指令  
证据性质：剔除极端行情口径下的回溯选择，不是独立样本外

## 决策与固定参数

用户明确选择“剔除极端行情”目标选出的单一40日下跌幅度分位候选，替换加权30/40日DRAQM
正式版本。新正式门控只计算：

```text
L40_t = max(-ln(C_t / C_{t-40}), 0)
```

并将其映射到严格滞后滚动504日历史分位，至少252个历史值，`L40=0`时分位固定为0。

- 55%：进入Defender；40%：恢复Momentum；
- 进入/恢复确认：1/1日；
- Momentum/Defender锁：30/30日，不可绕过；
- 不使用路径效率、波动率调整、地板、clip、30/40加权、Gold或紧急覆盖。

剔除极端行情只用于参数选择：以510300和黄金5日绝对对数收益划分固定20日块，冲击最高
10%的区块不参与排序；正式检查点仍完整保留全部1,841日。

不能表述为统计上优于旧正式版本。

## Badcase与前瞻

新路径共有20段实际Defender持仓，6段相对原Momentum跑输严格超过1个百分点，主要机制边界
包括：样本初期/V形恢复时30日锁的延迟、510300单一股票锚不能表达黄金和纳指的独立趋势、
以及55%附近单日入场对边缘风险信号较敏感。完整记录见`momentum_defender_badcases.md`。

参数从2026-08-25起冻结，下一未观察执行日起使用独立策略ID和前瞻账本；不得继续用相同历史
调整40日窗口、55%/40%阈值、1/1确认或30/30锁。旧加权DRAQM配置和检查点保留为显式回滚。
