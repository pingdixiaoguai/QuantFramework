# 四Momentum资产共同RAQM覆盖研究

## 决策

本研究不修改正式策略。正式策略继续为
`momentum_defender_c2_gold_raqm_w5_v1`，默认生产入口、配置、检查点和前瞻账本均保持不变。

把现有Gold RAQM覆盖推广到四只Momentum ETF后，回溯选择出的严格全启用组合可以把年化
从56.87%提高到57.93%、Sharpe从2.343提高到2.346，最大回撤保持-12.97%。但Sharpe增益
只有0.003，且经过两阶段回溯搜索后，年度块多重试验校正、walk-forward和bootstrap均不
支持晋升。综合过拟合风险为HIGH，结论是保留研究记录，不进入`strategy/configs/`。

## 固定边界

本实验只改变RAQM覆盖层：

- 基础C2状态机、沪深300慢门、30日最短持有和emergency完全不变；
- 原Momentum的Top1轮动、费用、行情和下一开盘执行完全不变；
- RAQM覆盖仍采用5个完整交易日硬持有；
- 基础C2恢复Momentum后，覆盖层交回原Momentum Top1；
- 同一候选内四只ETF与Defender必须使用相同公式、窗口和波动率地板；
- 四只ETF仅允许入场、退出差值阈值不同；
- 多只ETF同时满足入场条件时，选择“RAQM差值超过自身入场线”幅度最大的资产。

控制候选只启用Gold，并使用当前W5、`ER^1`、入场2.20、退出0.60时，与正式策略逐日收益
最大误差为0。

## 共同因子候选

统一公式写作：

```text
R_N       = ln(close_t / close_{t-N})
path_N    = Σ |ln(close_j / close_{j-1})|
ER_N      = |R_N| / path_N
vol_N     = std(日对数收益, N) × √N
floor_N   = 8% × √(N/252)
RAM_N     = clip(R_N / max(vol_N, floor_N), -3, +3)
score     = RAM_N × ER_N^p
```

共同搜索空间为窗口`N∈{5,10,20}`、效率比指数`p∈{0,0.5,1}`。严格四资产候选中，平衡
年化与Sharpe后仍由当前正式口径`N=5, p=1`胜出；RAQM10和RAQM20均明显更弱，没有理由
修改注册因子。

## 事件归因

候选覆盖29次，其中19次为Gold、10次为新增非Gold覆盖。新增事件7正3负：

- 最大正贡献：2022-06-06至2022-06-13创业板，相对正式策略+3.16%；
- 2023-03-28至2023-04-04创业板，+1.85%；
- 2023-10-31至2023-11-07沪深300，+1.33%；
- 最大负贡献：2023-12-15至2023-12-22纳指，-2.22%；
- 2021-12-10至2021-12-17沪深300，-0.98%；
- 2024-07-09至2024-07-16纳指，-0.95%。

前两大正事件占全部正向log贡献54.3%。逐一删除任一事件后，最低年化57.26%，仍略高于正式
策略；最低Sharpe 2.335，低于正式策略2.343，说明收益改善不依赖单一事件，但风险调整优势
并不稳固。

## 搜索与过拟合审计

- 单资产候选1,440组；
- 组合候选999组，其中第一阶段729组、观察结果后追加的局部细化270组；
- 唯一组合收益路径656条；
- 四资产全部启用的严格候选414组，其中27组回溯上同时改善年化、Sharpe和MDD；
- PBO 14.0%，但跨CSCV测试块击败正式基线的比例仅约1.3%；
- 扩展式walk-forward收益、Sharpe胜率均为20%；
- 年度块多重试验Reality Check `p=0.943`；
- 20日成对分块bootstrap：年化差为正概率78.3%，95%区间`[-1.54%, +3.79%]`；
- Sharpe差为正概率49.6%，95%区间`[-0.094, +0.080]`；
- 费用提高到5倍时，年化差仍为+0.88%，但Sharpe差转为-0.001；
- 综合过拟合风险：**HIGH**。

低PBO仅说明候选族内部的排名相对稳定，不代表它能击败正式基线。Reality Check、bootstrap
和walk-forward共同表明，约1个百分点的年化改善不足以覆盖两阶段选择偏差。

## 结论与后续边界

1. 四资产共用公式、使用资产专用阈值在机制上可行，机械审计全部通过。
2. 当前注册RAQM5优于本次测试的RAQM10、RAQM20和弱效率比公式。
3. 严格四资产历史候选可小幅提高核心指标，但Sharpe改善近乎为零。
4. 270组局部细化是在观察第一阶段后追加，不能称为预注册或样本外。
5. 不修改正式策略、不修改默认信号入口、不建立新的生产状态或持仓账本。
6. 若未来继续研究，应固定上述候选作为shadow并积累独立非Gold事件，而不是继续用相同历史
   调整阈值。
