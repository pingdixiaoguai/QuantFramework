# 510300单一40日下跌幅度分位：全量/剔除极端行情双目标寻参

日期：2026-08-25  
证据状态：预注册回溯双目标搜索，不是独立样本外  
结论：公式显著简化，但参数稳定性和收益证据不足，不替换当前加权DRAQM正式策略。

## 1. 固定机制

本实验不搜索因子窗口和公式。对510300收盘价定义：

```text
L40_t = max(-ln(C_t / C_{t-40}), 0)
```

将`L40`与严格早于当前信号的最近504个有限观测比较，至少需要252个历史值；`L40=0`时
分位固定为0。因子不使用30日窗口、30/40权重、Kaufman路径效率、波动率调整、8%地板或
`[-3,3]`剪裁。上一收盘分位最早在下一开盘执行。

只搜索状态参数：

- Defender进入分位：0.45至0.70，步长0.05；
- Momentum恢复分位：0.10、0.20、0.30、0.40，最小迟滞差0.10；
- 进入确认：1、3、5日；恢复确认：1、3日；
- Momentum/Defender锁：20、25、30日。

共1,242个候选ID、820条唯一收益路径。

## 2. 两种选择口径

完整样本目标使用全部1,841日选参。普通区间目标先用510300与黄金的原始5日绝对对数收益，
把历史切成固定20日块，剔除冲击最高10%的区块，共保留1,641日；掩码完全独立于候选参数。
剔除只用于排序，最终候选仍在完整1,841日上计算检查点。

两种目标分别把全样本/普通区间年化、Sharpe、三个固定分段最低Sharpe及六维参数邻域Q25
纳入排序，再在近似最优集合内优先1/1日确认、30/30日对称锁。

- 合并此前DRAQM研究后累计73,386个候选ID、42,816条唯一路径，全量/普通Reality Check

- 扩展walk-forward收益/Sharpe胜率均20%，leave-one-year均12.5%。

三倍费用下，两套候选年化分别47.96%和48.25%。所有置信区间均跨0，多重试验完全不支持
稳定优于当前正式策略。

## 6. 决策

单一40日下跌幅度分位确实实现了奥卡姆目标：去掉一个窗口、权重、路径效率、波动率地板和
剪裁；而且两种选择都自然回到最简单的1/1确认和对称30日锁。

但双目标没有在进入阈值上收敛，参数邻域远弱于当前加权DRAQM，完整年化下降约1.6至1.9个
百分点，Sharpe小幅改善没有统计支持。因此：

1. 当前正式`momentum_defender_downside_raqm_weighted_v1`保持不变；
2. 两套W40候选只保存为研究证据，不接入生产或默认日跑；
3. 若继续观察，应固定参数、不再用同一历史重搜，只做新数据影子比较。
