# 通用510300门控为何击败资产专用门控

## 核心判断

用户关于黄金的逻辑是正确的：当510300偏弱但黄金是Momentum Top-1时，继续持黄金确实创造
了历史价值；黄金自身DRAQM触发Defender也有效。资产专用策略落后的主因并不是黄金判断错误，
而是它同时取消了510300对创业板和纳指的市场状态保护。

通用门控的50.88%/1.721不是一个精确参数尖峰：相邻阈值和锁参数都会完整抓住决定性的
2022-08至11月Defender阶段。不过，它相对资产专用策略的全部领先确实高度集中在该阶段；
该阶段又主要受益于Defender于2022年11月切入港股通红利ETF后的单月大涨。因此更准确的
结论是：**通用门控具有真实的结构性保护价值，但“优于资产专用”的幅度含有显著历史事件运气。**

综合看，黄金相关两项贡献约+0.206 log excess；未门控成长资产和510300额外防守合计损失
约-0.395，净结果仍然落后。

## 决定性阶段：2022-08-05至11-28

这是两策略最大的差异事件：

- 通用门控：全程Defender，收益+24.98%；
- 资产专用：黄金53天、纳指17天、创业板5天，整体-0.23%；
- 单段log excess：资产专用-0.225；
- 占所有负向差异的38.5%；前两大负阶段占54.1%。

Defender底层路径：

|阶段|主要持仓|阶段收益|
|---|---|---:|
|2022-08-05—08-29|红利低波ETF 512890 100%|+6.90%|
|2022-09-06—10-21|10年国债ETF 511260 100%|-0.41%|
|2022-10-28—10-31|上证红利ETF 510880 100%|-4.03%|
|2022-11-01—11-25|港股通红利ETF 513530 100%|**+23.18%**|

通用510300门控并没有预测港股红利上涨；它只是让资金长期留在Defender，随后Defender内部的
`low_scene_reversal`机制恰好切到513530并捕获大涨。这是结构性“第二策略期权”，也是明显
的历史路径依赖。

## 删除该阶段后的排名

如果从两策略中同时删除2022-08-05至11-28：

|策略|年化|Sharpe|
|---|---:|---:|
|资产专用|49.49%|1.664|
|通用门控|48.77%|1.652|

资产专用反而领先。逐次删除整个2022年，两者年化也几乎相同：48.33%与48.29%。因此通用
门控相对资产专用的排名优势不能视为跨时期稳定事实。

## 通用门控是否过拟合

### 不是精确参数尖峰

- 最终参数附近16组邻域全部超过45%年化；邻域年化Q25 49.74%、Sharpe Q25 1.690；
- 入场0.50/0.55/0.60、退出0.10/0.20/0.30、25/30日锁等邻近参数，在决定性阶段均持有
  Defender 75—76天，阶段收益约23.29%—24.98%；
- 3倍费用年化49.75%；固定删除任一年最低年化45.98%；
- 通用门控相对Momentum共有17段差异事件，14正3负，删除任一事件最低年化46.97%。

所以不能把50.88%简单归因成某个阈值偶然命中。

### 但统计证据不足，且相对优势事件集中

- 通用门控候选族的年度Reality Check为`p=0.1742`，多重试验后不显著；
- 删除最大两个正贡献事件后年化降到43.84%；
- 相对资产专用的总领先小于2022-08至11月单段领先，去掉该段即反转排名。

结论：通用门控本身是一条表现较强、参数不脆弱的历史路径；但50.88%相对资产专用的优势
包含显著单事件运气，不能外推为通用门控必然更优。

## 更合理的机制方向

诊断性、未寻参反事实：保留通用510300门控，只在Top-1为黄金且黄金资产状态允许时覆盖：

|诊断反事实|年化|Sharpe|MDD|
|---|---:|---:|---:|
|通用510300门控|50.88%|1.721|-25.50%|
|通用门控 + 黄金持有例外|51.49%|1.722|-25.50%|
|通用门控 + 黄金双向判断|51.59%|1.725|-25.50%|

这不是正式候选：规则由已观察结果启发，尚未经过预注册网格、事件删除和全局多重试验。但它
验证了机制判断：

1. 对510300、创业板和纳指保留通用市场门控；
2. 仅当Momentum Top-1为黄金时，用黄金自身DRAQM决定是否豁免通用Defender；
3. 黄金自身明显转弱时仍允许额外切Defender；
4. 不要让成长资产因为“不是510300/黄金”而完全失去市场状态过滤。

## 最终结论

- 黄金逻辑正确，并非导致回测落后的原因；
- 资产专用版本的结构性错误是把创业板和纳指完全取消门控；
- 通用门控的绝对表现不只是一个参数尖峰；
- 但它相对资产专用的领先主要依赖2022年Defender捕获港股红利大涨，存在显著事件集中；
- 下一步最值得正式研究的是“通用510300门控 + 黄金例外”，不是二选一。
