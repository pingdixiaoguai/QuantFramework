# Defender高位部分切换Momentum：2019主样本奥卡姆审计

日期：2026-08-27  
证据状态：同一历史上的回溯机制审计，不是独立样本外证据  
结论：机制被否证；正式`momentum_defender_w40_qm40_threshold_v5`保持不变

## 1. 问题与固定边界

研究问题是：当Defender处于自身近期区间高位时，是否可以把部分Defender仓位切换到当前
Momentum Top1，从而提高当前正式策略的年化收益和Sharpe。

回测从2019-01-18重新初始化，截止2026-08-26，共1,844个开盘到收盘观测。以下正式层全部
冻结：

- v5的W40 756日历史、60%/35%迟滞和30日Momentum锁；
- Defender最低5日、510300 QM40>0.0075连续10日早退和30日fallback；
- 月度QM40最低的六只红利ETF Defender选择器；
- 黄金0.005/-0.020逃生、5日硬持有和即时入口否决；
- 正式Momentum Top1和5日换仓过滤；
- 前收盘信号、下一开盘执行及权益ETF单边1bp成本。

覆盖层只在正式v5最终可执行候选仍为Defender时生效。被减掉的Defender权重直接分给正式
策略当日已经确定的Momentum Top1；正式目标为Momentum或黄金时不做任何改动。

底层ETF权重级复算与正式候选级逐日收益的最大误差为`1.06e-8`。事件归因使用同一底层执行
引擎的无覆盖基线，避免把这个无害的成本顺序误差计成事件。

## 2. 三种奥卡姆实现

### 2.1 图示规则原样移植

固定使用512890作为信号锚，计算40日区间位置：

\[
q_t=\frac{C_t-L_{40,t}}{H_{40,t}-L_{40,t}}.
\]

2019重启时Defender网格从100%开始；此后每天`q<=10%`增加20个百分点、`q>=95%`减少20个
百分点，中间区间保持原档位。信号在收盘形成，下一开盘执行。网格连续运行，即使正式策略
当时不在Defender，仍保留状态，完全复用图示“有记忆”的含义。

### 2.2 Defender段内网格

只在正式策略实际处于Defender时逐档调整；离开Defender立即恢复100%，避免非Defender时期
积累一个与实际持仓脱节的低网格状态。

### 2.3 单次部分切换

取消记忆。只有当前开盘的区间位置达到高位线时，才把固定10%或20%从Defender转给Momentum；
下一日不再满足即恢复100% Defender。这是自由度最低、风险最小的解释。

信号锚分别检查固定512890和当月实际选中的Defender ETF。局部敏感性只围绕已有规则展开：
窗口30/40/50日、高位线90%/95%/100%、步长10%/20%，低位线固定10%。两种锚、三种规则共
108个参数ID，全部产生不同逐日路径。该网格用于否证与稳健性检查，不用于继续拟合正式策略。

## 3. 核心结果：108条路径无一双指标提高

|方案|年化|Sharpe|MDD|相对年化|相对Sharpe|
|---|---:|---:|---:|---:|---:|
|正式v5|58.43%|1.886|-25.50%|—|—|
|图示原样：512890连续网格40/10%/95%/20%|48.71%|1.610|-25.50%|-9.72个百分点|-0.276|
|512890高位当天仅转20%|57.63%|1.873|-25.50%|-0.80个百分点|-0.013|

|全表最少退化：实际Defender、40日、最高点、仅转10%|58.11%|1.881|-25.50%|-0.31个百分点|-0.006|

完整108条路径中：

- 完整样本年化与Sharpe同时提高：0条；
- 同时通过完整样本、2019–2022开发段和2023–2024验证段：0条；
- 最大回撤没有改善，主候选与最少退化候选都保持-25.50%；
- 六个机制族各自的最佳年化差和最佳Sharpe差仍然全部为负。

分家族的最好结果同样没有正向例外：固定512890的单次切换最好仍损失0.40个百分点年化和
0.006 Sharpe；实际Defender的单次切换最好损失0.31个百分点和0.006。段内记忆网格最好的
年化损失分别为3.13和2.30个百分点；连续网格最好的年化损失分别为9.11和7.20个百分点。

## 4. 原图规则为什么退化严重

图示连续网格在正式574个Defender日中有413日发生部分切换，平均Defender权重只有44.25%，
其中232日被连续高位信号压到0%。它实质上不再是“少量逃生”，而是在风险门已经选择Defender
之后长期重新暴露于Momentum，因此年化和Sharpe在开发、验证、近期三段全部大幅下降：

|区间|正式年化 / Sharpe|连续网格年化 / Sharpe|
|---|---:|---:|
|2019–2022开发|50.05% / 1.893|41.93% / 1.605|
|2023–2024验证|67.40% / 1.817|52.75% / 1.514|
|2025–2026近期|68.85% / 2.036|61.00% / 1.795|

但“过于激进”不是唯一原因。最少退化的无记忆方案只在75个Defender日转出10%，Defender日
平均权重仍有98.69%，仍然无法超过基线。这说明机制方向本身没有历史边际优势。

## 5. 最少退化方案也不稳健

全表诊断领先项为：当月实际Defender ETF的40日位置恰好等于最高点时，当天只转10%给
Momentum，无记忆。它在开发段小幅提高0.17个百分点年化和0.008 Sharpe，但验证段损失0.70
个百分点和0.012，近期损失1.15个百分点和0.025。

逐年删除任意一年后，它的年化和Sharpe仍然每次都低于正式v5，双指标通过率为0%。29段真实
差异事件中11段为正、18段为负；主要负事件的幅度大于主要正事件：

- 2021-08-27至2021-09-15：log超额-0.706个百分点；
- 2026-03-12至2026-03-19：-0.660个百分点；
- 2023-05-04至2023-05-09：-0.575个百分点；
- 最大正事件2024-01-08至01-09仅+0.345个百分点。

按自然年，它在2019、2022和2024有正贡献，但2023、2025和2026持续回吐；2023收益差
-1.21个百分点、Sharpe差-0.053，2026收益差-0.91个百分点、Sharpe差-0.032。因此不是一个
可以靠删除单一异常年份修复的结果。

## 6. 过拟合与压力检查

- 20日块、5,000次配对Bootstrap：诊断领先项年化差均值-0.32个百分点，95%区间
  `[-1.02, +0.25]`个百分点，年化差为正概率15.76%；Sharpe差均值-0.0057，95%区间
  `[-0.0217, +0.0082]`，为正概率22.78%。
- 108条路径年度Reality Check `p=0.9964`；观察到的全表最佳年均log超额本身就是负数。
- CSCV-PBO为9.74%，但训练选中者在测试块击败正式基线的比例只有0.22%。低PBO只表示这些
  失败候选之间的相对排序较稳定，不能把“稳定选出最少退化者”误读成可战胜基线。
- 扩展walk-forward重选双指标胜率20%；留一年重选为50%，但固定诊断候选删任一年为0%。
- 252日滚动双胜率39.2%，504日降至22.9%，观察窗口越长越不支持该机制。
- 三倍成本下诊断领先项年化/Sharpe差扩大至-0.36个百分点/-0.007；十倍成本为-0.52个
  百分点/-0.011。主结论不是由1bp成本造成，但额外换仓只会继续恶化。

## 7. 机制解释与决策

区间高位只说明红利ETF接近自身近期高点，并不说明当前Momentum Top1未来会跑赢它。当前
正式策略进入Defender前已经经过CSI300 W40风险门，退出又已有QM40恢复强度与黄金逃生；在
风险门仍选择Defender时，仅凭Defender价格高位重新增加Momentum暴露，历史上更像重复甚至
对抗已有恢复机制。实际事件也显示，Defender高位经常是其自身趋势仍在延续，而不是应当卖出
给Momentum的反转点。

因此按奥卡姆原则作出以下决定：

1. 不把Defender高位部分切换Momentum加入正式v5；
2. 不建立影子候选，因为连最小10%无记忆版本的点估计也低于正式策略；
3. 不在同一历史继续细化窗口、高位线、步长或增加第二个过滤器；
4. 正式配置、生产入口、治理记录和前瞻账本均保持不变。
