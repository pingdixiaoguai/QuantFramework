# 共同DRAQM score × 极端行情修剪寻参

## 结论

本轮确认标的是`510300.SH`和`518880.SH`。两只ETF的score公式、窗口、权重、RAQM正则化、
历史分位口径完全一致，只允许进出阈值和确认天数不同。持有创业板或纳指时不检查DRAQM。

最终共同score为：

```text
Score = 25% × P(DRAQM20) + 75% × P(DRAQM40)
```

参数选择时，先把510300和518880的5日绝对对数收益合并成候选无关的冲击分数，按固定20日
块切分93段，删除分数最高的10段、共200个交易日，只用剩余89.14%的普通区间进行候选排序。
最终回测、回撤、事件和费用指标仍包含全部1,841个交易日。

最终研究候选全样本年化47.47%、Sharpe 1.621，普通区间年化40.94%、Sharpe 1.785。
它明显优于纯Log-QM Momentum，但仍弱于通用510300门控的50.88%/1.721，因此不替换现有
候选，也不自动晋升生产。

## 共同score公式

对任意资产和窗口`X∈{20,40}`：

```text
R_X    = log(close_t / close_{t-X})
ER_X   = |R_X| / sum(|daily_log_return|, X)
vol_X  = std(daily_log_return, X) * sqrt(X)
RAQM_X = clip(R_X / max(vol_X, 8% * sqrt(X/252)), -3, 3) * ER_X
D_X    = max(0, -RAQM_X)
P_X    = D_X相对此前504日、不含当日的经验分位；D_X=0时P_X=0
Score  = 0.25 * P_20 + 0.75 * P_40
```

所有收盘数据最早在下一开盘使用。

## 资产阈值与状态规则

### Momentum Top-1为510300

- `Score >= 0.35`：Defender入场证据，确认1日；
- `Score <= 0.25`：Momentum恢复证据，确认1日。

### Momentum Top-1为518880

- `Score >= 0.50`：Defender入场证据，连续确认3日；
- `Score <= 0.05`：Momentum恢复证据，确认1日。

其他规则：

- Momentum锁25日，Defender锁23日；
- Defender期间持续监控最初触发入场的资产；
- 159915和513100不检查、不累计DRAQM证据；
- 没有短周期桥接、Gold覆盖或紧急破锁。

## 极端块修剪

主口径：

```text
Shock_t = max(
  |log(P510300_t / P510300_{t-5})|,
  |log(P518880_t / P518880_{t-5})|
)
```

以2019-01-18为锚点，每20个交易日固定成块，块分数取块内`Shock_t`最大值，删除排名最高
的10%块。该掩码只由ETF价格决定，与任何策略候选收益无关。

剔除块包括2019年春季快速行情、2020年初及3—4月、2020年6—7月、2024年9—10月，
以及2025—2026年黄金/权益大幅波动区间。完整日期见
`raw_shock_blocks.csv`。

为防止修剪规则本身过拟合，另用“5日绝对收益/20日波动率”形成第二套极端块。两个宽网格
独立选出了相同的共同score和初始阈值族；最终候选在第二套普通区间仍有37.20%年化、
1.597 Sharpe。

## 参数稳定性

对最终参数逐次只改变一个进出线、确认期或锁定期，共23个直接邻域：

- 邻域全样本年化Q25：46.22%；
- 邻域全样本Sharpe Q25：1.585；
- 原始修剪普通区间年化/Sharpe Q25：39.73%/1.743；
- 波动调整修剪普通区间年化/Sharpe Q25：35.88%/1.546；
- 最终参数是邻域全样本年化和原始修剪Sharpe最高点；
- Defender锁22—25日形成连续平台，23日为平台代表；
- 510300入场0.30/0.35、黄金入场0.45/0.50、黄金恢复0/0.05/0.10及Momentum锁20/25/30
  多组参数产生相同路径，最终取中间值。

3倍费用下年化46.39%、Sharpe 1.593。逐次删除任一年最低年化41.55%、最低Sharpe 1.573；
删除任一Defender事件后最低年化44.91%、Sharpe 1.541。

## 全局过拟合审计

把此前资产专用研究和本轮共同score研究全部纳入，共38,631个候选ID，按逐日收益哈希去重为
5,259条路径：

- 全样本CSCV-PBO：18.83%；
- 原始修剪/波动调整修剪PBO：2.81%/3.03%；
- 全样本Reality Check：`p=0.1400`；
- 原始修剪/波动调整修剪Reality Check：`p=0.0886`/`p=0.0742`；
- 全局walk-forward相对Momentum收益/Sharpe胜率：80%/80%；
- 配对分块Bootstrap相对Momentum的年化差95%区间为+2.14至+25.87个百分点，Sharpe差
  为+0.133至+0.810；
- 相对通用510300门控的Reality Check为`p=0.9952`，没有替换依据。

全样本多重试验仍未达到常用显著性标准；普通区间结果更稳定，但不能把修剪后的低PBO当成独立
样本外证据。

## 事件证据

- 510300触发9次，8正1负；
- 518880触发3次，3次均为正；
- 黄金历史事件仍然偏少，阈值不确定性高于510300；
- 截至2026-08-21，策略处于Momentum，Top-1为518880。

最终判断：共同score和极端块修剪显著降低了口径自由度，形成比上一版资产异构参数更普适的
研究候选；但它仍未超过通用510300门控，因此只保留研究状态。
