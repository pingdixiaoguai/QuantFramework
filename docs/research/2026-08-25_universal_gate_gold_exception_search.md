# 通用510300门控 + Gold例外：奥卡姆分层寻参

## 机制

本轮严格实现“保留510300通用门控，只在Top-1为黄金时允许黄金覆盖”：

1. 510300基础状态机独立、连续运行；Gold永不修改其确认 streak、锁或当前状态；
2. Top-1不是黄金时，最终目标完全等于510300基础状态；
3. Top-1为黄金时，Gold状态可豁免基础Defender；双向模式还允许黄金自身转弱时额外切Defender；
4. Top-1离开黄金后，Gold状态重置，立即交回基础状态；
5. Gold覆盖不增加额外持有锁，仅使用阈值和确认期；基础Momentum/Defender锁搜索
   `0/5/10/15/20/25/30`日。

这比之前的混合状态机更简单，也确保Gold参数不会偷偷改变510300基础状态。

## 包含极端行情寻参

### 510300基础门控

```text
Score = 25% * P(DRAQM30) + 75% * P(DRAQM40)
入场 >= 0.55，确认3日
恢复 <= 0.30，确认1日
Momentum/Defender锁 = 30/30日
```

### Gold双向覆盖

```text
Score = 50% * P(DRAQM30) + 50% * P(DRAQM40)
入场Defender >= 0.40，确认1日
恢复Gold <= 0.00，确认3日
模式 = bidirectional
```

结果：全样本年化50.26%、Sharpe 1.689、MDD -25.50%；普通区间42.60%/1.845。

## 不包含极端行情寻参

### 510300基础门控

```text
Score = 25% * P(DRAQM20) + 75% * P(DRAQM40)
入场 >= 0.55，确认3日
恢复 <= 0.20，确认1日
Momentum/Defender锁 = 20/30日
```

### Gold豁免

```text
Score = 25% * P(DRAQM20) + 75% * P(DRAQM40)
Gold弱线 >= 0.60，确认1日
Gold健康线 <= 0.20，确认3日
模式 = exemption_only
```

结果：全样本年化48.45%、Sharpe 1.668、MDD -25.50%；普通区间43.80%/1.924。

普通区间候选按奥卡姆规则选择了更简单的单向豁免；全样本候选只有在双向模式明显提高收益时
才接受额外复杂度。

## 与通用510300门控比较

|策略|年化|Sharpe|
|---|---:|---:|
|通用510300门控|50.88%|1.721|
|Gold例外—包含极端行情|50.26%|1.689|
|Gold例外—不包含极端行情|48.45%|1.668|

Gold覆盖本身在覆盖日贡献为正，但重新选择的510300基础参数及Gold重置语义使整体仍未超过通用
门控。配对Bootstrap相对通用门控的差值区间均跨0，未证明升级。

此前诊断反事实的51.59%使用了完整资产专用状态机的跨资产历史记忆，不是纯Gold覆盖；严格
奥卡姆机制无法复现，说明那部分收益依赖更复杂、难解释的状态交互。

## 决策

两套Gold例外策略均显著优于纯Momentum，且普通区间Sharpe很高；但未同时提高通用门控的
年化与Sharpe，因此保留为研究候选，不替换现有策略。
