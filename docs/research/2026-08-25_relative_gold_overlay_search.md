# 固定通用门控后的Gold相对Defender覆盖研究

日期：2026-08-25  
证据状态：预注册回溯搜索，不是样本外  
结论：机制方向优于绝对Gold分位门控，但不足以替换冻结的通用510300门控。

## 1. 问题与最小机制

上一轮失败的关键不是“黄金一定不该豁免”，而是绝对Gold DRAQM只能回答黄金是否偏弱，不能
回答黄金是否强于当时实际可持有的Defender。尤其在2022-11-11至11-28，黄金上涨3.79%，
Defender上涨12.24%，绝对Gold规则仍会错过更强的Defender。

本轮因此固定现有通用510300状态及30/30日锁，禁止Gold寻参改写基础状态。只有Momentum
Top-1为黄金时，新增一层Gold相对Defender判断；离开黄金后立即清空覆盖层状态。

对连续净值曲线`C`和窗口`h`，在收盘`t`计算：

```text
r_t       = ln(C_t / C_{t-1})
R_{t,h}   = ln(C_t / C_{t-h})
ER_{t,h}  = |R_{t,h}| / sum_{i=t-h+1}^t |r_i|
sigma     = max(std(r_{t-h+1:t}) * sqrt(h), 0.08 * sqrt(h/252))
Q_{t,h}   = clip(R_{t,h} / sigma, -3, 3) * ER_{t,h}
```

若配置包含多个窗口，则`Q`按固定权重加权。下一开盘可用的三个量为：

```text
G = Gold signed RAQM at previous close
D = whole-Defender signed RAQM at previous close
Delta = G - D
```

进入Gold豁免要求`G > 0`、`Delta >= entry_difference`并满足连续确认；退出要求Gold转弱
`G <= 0`，或`Delta <= exit_difference`。相对差退出受Gold最短持有约束，Gold转弱为安全退出，
可绕过该约束。所有信号均由上一收盘映射到下一开盘，切换日复合旧标的退出腿与新标的进入腿。

## 2. 预注册搜索

- 窗口：20、30、40，以及20/40和30/40的25%/75%加权；
- 相对入场差：0.0、0.1、0.2、0.3、0.4；
- 相对退出差：-0.2、-0.1、0.0、0.1，最小滞后差0.1；
- 入场确认：1、3、5日；退出确认：1、3日；
- Gold覆盖锁：0至30日的5日倍数；
- 模式：单向豁免与双向覆盖；
- 选参目标：全样本与候选无关的普通区间分别选择；最终绩效均保留完整日期。

实际测试7,140个候选ID，去重为2,762条收益路径。全样本、普通区间、development、
validation、recent、参数邻域均进入预注册排序；选择规则先要求各稳健指标排名不出现明显短板，
再在近似最优区采用奥卡姆复杂度。

## 4. 稳健性与过拟合审计

### 参数邻域

- 全样本稳健候选有72个单步邻域；年化/Sharpe Q25为49.85%/1.681，只有12.5%的邻居超过
  选中参数的年化与Sharpe。前两大正事件占全部正事件贡献97.44%，仍有明显事件集中。
- 普通区间候选有48个邻域；普通区间年化/Sharpe Q25为42.29%/1.833，没有邻居超过选中
  参数的普通区间年化或Sharpe，显示所选点位于局部上沿而不是宽平台中心。

### Bootstrap、事件与费用

- 全样本稳健候选相对通用门控的年化差95%区间为`[-3.12%, +4.44%]`，Sharpe差区间为
  `[-0.098, +0.087]`；两者均跨0。
- 探索性冠军年化差均值为+0.90个百分点，但95%区间仍为`[-3.51%, +5.80%]`；Sharpe差
  均值近0，区间为`[-0.115, +0.113]`。
- 删除任一覆盖事件后，全样本稳健候选最低年化49.86%、最低Sharpe 1.691，均低于通用门控。
- 三倍费用下，全样本稳健候选年化49.97%、Sharpe 1.684；普通区间候选年化49.76%、
  Sharpe 1.680。

Gold规则”这一说法。

## 5. 决策

相对Gold-vs-Defender是比绝对Gold DRAQM更正确的机制表达：它避免了“黄金不弱但Defender
更强”的错误豁免，并把全样本结果从上一轮50.26%/1.689改善到稳健候选51.18%/1.715，探索
冠军51.83%/1.724。

但增量很小、Bootstrap跨0、邻域不宽、事件集中，且全局多重试验完全不显著。因此：

1. 不替换`momentum_defender_downside_raqm_weighted_v1`通用510300门控；
2. 两个预注册候选仅冻结为研究证据，不接入生产；
3. 若继续，只允许从2026-08-24之后的未观察数据做影子验证，不再用同一历史移动阈值。

机器证据位于`experiments/20260825_momentum_defender_relative_gold_overlay_search/`。
