# 弱趋势状态风险干预：冻结设计

phase5 表明，无条件正动量安全腿在 D/V 同时改善三目标，却在 2024—2026 强趋势阶段稀释收益；phase6 的稀疏 RA 点又缺乏局部稳定性。本轮事先固定一个新机制假设：**风险因子只在赢家自身趋势已经不强时拥有否决权；强趋势赢家保持100%仓位。**

共同触发条件：QM20赢家的拟合风险为四资产最高且不低于 `0.70 / 0.80`，备选资产20日点对点动量为正。备选选择两种：最低风险 `SAFE`；或最大化 `QM排名 - 0.75×风险` 的 `RA`。

候选状态门槛：

1. `MOMCAP`：赢家20日点对点动量不高于 `5% / 10% / 15% / 20%`，风险预算 `15% / 25% / 35%`；
2. `DRAWDOWN`：赢家相对过去60日最高收盘回撤至少 `2% / 5% / 8%`，风险预算 `15% / 25% / 35%`；
3. `BOTH`：同时满足赢家20日动量不高于 `10% / 15%`、60日高点回撤至少 `2% / 5%`，风险预算 `20% / 30%`。

共116个候选。只用D/V选择；两段均须同时改善Sharpe、年化和Top10平均回撤。排序沿用phase5六项最弱标准化改善分数，并在同分时优先较少触发、较低预算。T不参与选择。最终要求D/V/T/FULL三目标全部为正、5bp方向为正、滚动36个月Sharpe领先率不低于60%、最大回撤不恶化超过1pp。由于T已经在前序研究中可见，结论仍只属于事后机制研究。
