# RSI14 资产专属权重研究

## 结论

本轮在上一阶段统一 RSI14 权重研究之上，允许四只 ETF 使用不同的 RSI 敏感度。
为了避免较大权重给某资产增加永久分数，反向 RSI 横截面排名先减去当日排名中心，
再乘资产权重：

`综合分 = QM20排名 + 资产RSI权重 × (反向RSI14排名 - 当日排名中心)`

训练期按单边 5bp 成本、4 个连续子区间稳定性筛选后，冻结候选为：

| 标的 | RSI14 权重 |
| --- | ---: |
| `510300.SH` | 0.9 |
| `159915.SZ` | 0.3 |
| `513100.SH` | 0.3 |
| `518880.SH` | 0.3 |

候选使用 `rebalance_days=2`。它在零成本和 1/3/5bp 单边成本下都同时提高全期
年化与 Sharpe；单边 10bp 时优势消失。尽管成本表现明显好于上一阶段的统一 0.6
权重，bootstrap、滚动窗口、局部邻域和逐一剔除资产的证据仍不够强，因此治理结论
仍是：

> 保存为 `cost_aware_quasi_oos_shadow_only`，不修改生产
> `quality_momentum_top1.yaml`。

## 研究设计

- 数据、HFQ、T+1 开盘成交、资产池及 70/30 分割与上一阶段完全一致；分割日为
  2022-08-31，数据截止 2026-08-17。
- 每只资产权重取 `{0, 0.3, 0.6, 0.9}`，持有期取 `{1, 2, 3, 5}`，共
  `4^4 × 4 = 1,024` 组。
- 选择阶段只读取训练期的 5bp 成本后收益。
- 候选必须满足：训练全段年化与 Sharpe 均超过同成本基准；4 个连续训练子段中
  至少 3 段双提升；四资产权重不能完全相同。
- 合格候选按子段年化和 Sharpe 中位改善的较弱项排序，再以全训练段联合改善和
  较小权重离散度打破并列。
- 参数冻结后才计算后段绩效。本项目此前已经读取过相同后段的统一权重结果，
  因而这里只能称 quasi-OOS，不能重新包装成完全未见样本。
- 快速研究引擎与正式回测引擎的 3,173 个候选日收益逐点一致，容差 `1e-14`。

训练门槛最终只有 12/1,024 组通过。训练期 5bp 基准年化/Sharpe 为
23.90%/1.006，冻结候选为 24.72%/1.032，并在 4 个子段中有 3 段双提升。

## 绩效

### 零成本上限

| 区间 | 基准年化 / Sharpe | 统一 0.6 权重 | 资产专属候选 | 候选最大回撤 |
| --- | ---: | ---: | ---: | ---: |
| 训练 | 26.85% / 1.103 | 30.72% / 1.222 | 29.42% / 1.185 | -25.27% |
| 后段 | 39.56% / 1.269 | 52.23% / 1.528 | 43.45% / 1.359 | -28.15% |
| **全期** | **30.56% / 1.155** | **36.87% / 1.322** | **33.50% / 1.240** | **-28.15%** |

资产专属候选的零成本年化提高 2.95 个百分点，Sharpe 提高 0.085，但最大回撤
比基准扩大 2.40 个百分点。`Σ|Δw|` 年化换手为 71.40，高于基准 47.41，
但远低于统一 0.6 权重的 160.67。

### 5bp 选择与验证口径

| 区间 | 5bp 基准年化 / Sharpe | 5bp 候选年化 / Sharpe | 是否双提升 |
| --- | ---: | ---: | :---: |
| 训练 | 23.90% / 1.006 | 24.72% / 1.032 | 是 |
| 后段 | 36.23% / 1.188 | 38.85% / 1.249 | 是 |
| **全期** | **27.50% / 1.064** | **28.82% / 1.102** | **是** |

5bp 全期年化提高 1.32 个百分点，Sharpe 提高 0.038；最大回撤为 -28.62%，
基准为 -26.22%。成本后的收益和 Sharpe 改善仍以更深回撤为代价。

### 成本压力

| 单边成本 | 基准年化 / Sharpe | 统一 0.6 权重 | 资产专属候选 | 候选是否双提升 |
| ---: | ---: | ---: | ---: | :---: |
| 0bp | 30.56% / 1.155 | 36.87% / 1.322 | 33.50% / 1.240 | 是 |
| 1bp | 29.94% / 1.137 | 34.69% / 1.261 | 32.56% / 1.212 | 是 |
| 3bp | 28.72% / 1.101 | 30.44% / 1.139 | 30.68% / 1.157 | 是 |
| 5bp | 27.50% / 1.064 | 26.31% / 1.017 | 28.82% / 1.102 | 是 |
| 10bp | 24.52% / 0.973 | 16.56% / 0.712 | 24.30% / 0.965 | 否 |

资产专属权重的主要价值不是取得最高零成本回报，而是减少统一权重方案的过度换手，
使 RSI 增量在 5bp 下仍保持正向。

## 过拟合检验

| 检验 | 结果 | 判读 |
| --- | --- | --- |
| 训练搜索稀疏度 | 12/1,024 组通过训练门槛 | 合格区域较窄 |
| 5bp 后段 | 年化 38.85% vs 36.23%；Sharpe 1.249 vs 1.188 | 参数冻结后的方向为正，但后段曾在上一研究被观察 |
| 5bp 滚动 36 月 | 64/116（55.2%）窗口双提升 | 仅略高于半数，周期稳定性一般 |
| 局部权重邻域 | 9/54（16.7%）邻域在训练和后段都双提升 | 参数面不宽，存在明显离散敏感性 |
| 权重位置置换 | 同一 `{0.9,0.3,0.3,0.3}` 的 4 种映射中冻结映射排名第 1 | 较高 RSI 权重放在 510300 具有样本支持 |
| 逐一剔除资产 | 1/4 三资产池双提升 | 结果依赖完整四资产结构，跨池泛化弱 |
| 配对 20 日块 bootstrap | 年化差 95% CI `[-8.64pp, +10.74pp]`，正差概率 59.6% | 区间跨零，证据弱 |
| Sharpe bootstrap | 差值 95% CI `[-0.260, +0.315]`，正差概率 59.7% | 无法排除随机路径造成的改善 |
| 10bp 压力 | 年化与 Sharpe 均略低于基准 | 成本安全边际有限 |

综合来看，候选满足“历史年化与 Sharpe 双提升”以及“5bp 后仍双提升”，也优于统一
权重候选的成本退化；但局部参数平台、跨池和 bootstrap 均未达到生产部署所需的
强度。尤其只有 1/4 leave-one-out 资产池通过，说明四只资产及其权重映射共同构成
结果，不能把它泛化为普遍的 RSI 资产定价规律。

## 治理决定

1. `CompositeTop1` 支持可选 `asset_weights` 和 `center_rank`；旧配置不设置它们时
   行为完全不变。
2. 保存
   `strategy/configs/quality_momentum_rsi14_asset_weighted_top1_research.yaml`，
   显式写入 5bp 研究成本与 `cost_aware_quasi_oos_shadow_only` 状态。
3. 不修改生产配置，不把本次后段称为干净 OOS。
4. 若继续 paper-shadow，冻结上述四个权重、QM20、RSI14、rd=2 和 5bp 评价口径；
   只允许使用 2026-08-18 之后的新数据更新监测，不再回看历史调参。
