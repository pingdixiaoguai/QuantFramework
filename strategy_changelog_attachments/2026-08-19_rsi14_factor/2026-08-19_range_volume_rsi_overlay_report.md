# 回撤、低点涨幅、量能与 RSI14 辅助 QM20 的研究

## 结论

本研究实现了三个不使用未来数据的通用因子，并在单边 5bp 成本下搜索了 1,440
组“质量动量 + 区间位置 + 量能 + RSI14”策略。冻结候选在 2016 年以来的全历史
回测中，确实相对当前生产策略同时提高了年化收益和 Sharpe：年化从 26.81% 提高到
33.34%，Sharpe 从 1.072 提高到 1.369，最大回撤从 -26.22% 收窄到
-20.42%。

但这不是可部署的“双赢”。在未参与训练的 2022-09-01 至 2026-08-17 样本外：

- 候选年化 33.58%、Sharpe 1.341；
- 当前策略年化 36.23%、Sharpe 1.188，候选没有同时胜出；
- 候选与相同 `rebalance_days=10` 的纯 QM20 对照日收益完全相同，958 个样本外
  交易日中收益差异为 0 天。

因此，全历史改善混合了降低换手和样本内少量换仓事件的贡献，回撤、低点涨幅、
量能和 RSI14 在样本外没有显示增量。候选状态冻结为
`rejected_no_oos_signal_increment`，不修改生产配置。

## 信号定义

所有滚动窗口都只使用当日及此前数据。设区间窗口 `X=60`、历史分位窗口
`H=504`：

- 回撤幅度：`(60 日最高收盘价 - 当日收盘价) / 60 日最高收盘价`，再计算其
  504 日时间序列分位点；
- 相比低点涨幅：`当日收盘价 / 60 日最低收盘价 - 1`，再计算其 504 日时间
  序列分位点；
- 量能：`当日成交量 / 60 日平均成交量`，再计算其 504 日时间序列分位点；
- RSI14：Wilder 平滑 RSI，范围 0～100。

前三个因子首个有效值需要 563 个观测。滚动分位计算包含当前观测，但不包含任何
未来观测。

## 搜索与候选冻结

研究数据为本地固定基线 HFQ 数据，资产池为 `510300.SH`、`159915.SZ`、
`513100.SH`、`518880.SH`。信号在 t 日收盘后生成，t+1 日开盘成交。统一从
2016-01-01 开始评价，以避免不同长窗口拥有不同的评价起点；训练截止日为
2022-08-31，之后的数据只用于冻结候选的样本外检验。

网格覆盖：

- `X ∈ {10, 20, 40, 60}`；
- `H ∈ {126, 252, 504}`；
- 区间位置、量能、RSI 的 8 种可解释方向组合；
- 辅助信号强度 `α ∈ {0.25, 0.5, 1.0}`；
- `rebalance_days ∈ {1, 2, 3, 5, 10}`。

每组试验都同时启用回撤、低点涨幅、量能和 RSI，而不是事后只保留有利信号。
1,440 组中，110 组通过“训练期相对当前策略整体双提升、四个训练子区间至少三个
双提升”的门槛；其中 23 组还通过相同调仓周期 QM20 的归因门槛。

冻结候选为：

- `X=60`、`H=504`、`α=0.25`、`rebalance_days=10`；
- 偏好历史上较深的回撤、较低的离开低点涨幅、较高量能和较低 RSI；
- 综合分数为：
  `rank_cs(QM20) + 0.25 × [2(Pdd-0.5) - 2(Prise-0.5) + 2(Pvol-0.5) - (RSI-50)/50]`。

## 核心绩效

下表均包含单边 5bp 成本：

| 策略 / 区间 | 年化 | Sharpe | 最大回撤 |
| --- | ---: | ---: | ---: |
| 当前 QM20、rd=5，训练 | 21.56% | 1.001 | -21.99% |
| 同周期 QM20、rd=10，训练 | 28.09% | 1.205 | -19.67% |
| 候选，训练 | 33.21% | 1.387 | -19.67% |
| 当前 QM20、rd=5，样本外 | 36.23% | 1.188 | -26.22% |
| 同周期 QM20、rd=10，样本外 | 33.58% | 1.341 | -20.42% |
| 候选，样本外 | 33.58% | 1.341 | -20.42% |
| **当前 QM20、rd=5，全期** | **26.81%** | **1.072** | **-26.22%** |
| **同周期 QM20、rd=10，全期** | **30.10%** | **1.257** | **-20.42%** |
| **候选，全期** | **33.34%** | **1.369** | **-20.42%** |

候选在训练期只比同周期 QM20 多产生 20 个不同的每日目标，约占训练期 1.23%。
样本外仅 2024-09-20 出现一次目标差异，但因 10 日调仓节奏没有改变实际持仓和
收益。辅助信号的历史优势高度集中在少数训练期事件中。

零成本下，全期当前策略、同周期对照、候选分别为 29.80% / 1.164、
32.15% / 1.324、35.57% / 1.442。1、3、5、10bp 成本压力下，候选全期都
优于当前策略；然而各成本下的样本外候选仍与同周期 QM20 完全相同，所以成本压力
不能弥补信号增量证据的缺失。

## 过拟合检验

| 检验 | 结果 | 判读 |
| --- | --- | --- |
| 冻结样本外 | 候选年化低于当前策略；与同周期 QM20 的 958 个日收益完全一致 | 未通过主要信号增量门槛 |
| 正式引擎复现 | 候选 2,631 个正式日收益逐点一致 | 排除快速研究实现偏差 |
| 参数邻域 | 48 个邻近参数中仅 6.25% 在训练、测试均双胜同周期 QM20 | 优势不是宽广参数平台 |
| 36 月滚动窗口 | 对当前策略 70/87 双赢；对同周期 QM20 69/87 双赢 | 多数窗口包含样本内事件，不能替代冻结样本外结果 |
| 配对块 bootstrap：对当前策略 | 年化差 95% CI `[-7.62pp, +20.03pp]`；Sharpe 差 `[-0.016, +0.678]` | 两项区间都跨零 |
| 配对块 bootstrap：对同周期 QM20 | 年化差 95% CI `[-3.08pp, +7.66pp]`；Sharpe 差 `[-0.104, +0.237]` | 信号增量统计证据不足 |
| 留一资产池 | 对同周期 QM20 为 3/4 双赢；对当前策略仅 2/4 双赢 | 对资产池选择敏感 |

因子消融进一步削弱了 RSI 的解释力：移除 RSI 后，训练期年化 / Sharpe 从
33.21% / 1.387 上升到 34.58% / 1.443，全期也从 33.34% / 1.369 上升到
34.21% / 1.404；样本外仍与同周期 QM20 相同。也就是说，RSI14 在冻结组合里
没有提供独立、稳定的正贡献。移除量能后的事后结果虽在样本外略有改善，但这是读取
测试段后的消融观察，不能据此更换候选或宣称新 OOS 胜者。

## 治理决定

1. 合入三个通用因子、注册表和测试，供后续研究复用。
2. `CompositeTop1` 增加原始中心化值评分能力，以准确表达时间序列分位与 RSI
   幅度，不改变既有默认排名行为。
3. 保存研究配置，但明确标为 `rejected_no_oos_signal_increment`。
4. 不修改生产 `quality_momentum_top1.yaml`，不把候选用于实盘。
5. 若继续 shadow，只能使用本报告已冻结的参数，并从 2026-08-18 之后积累新的
   未见数据；未来评价必须同时对比当前 rd=5 和同周期 rd=10 QM20，避免把降低
   换手误归因于辅助信号。
