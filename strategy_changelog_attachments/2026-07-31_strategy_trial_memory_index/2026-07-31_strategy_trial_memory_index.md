## 1. 共同基准与口径

除特别注明外，本轮候选池回测均沿用：


原4ETF基准在 2013-07-30 ～ 2026-07-23 的代表性结果为：累计收益 `2451.44%`、CAGR `29.52%`、Sharpe `1.124`、最大回撤 `-25.79%`。

不同新增ETF上市时间不同，单项报告有少量交易日对齐差异；短历史标的的“全历史”数字实际包含很长一段尚未进入候选池的时期，必须结合严格共同窗口解读。

## 2. 大候选池与替换实验

### 2.1 一次性扩展到10只

候选池：

```text
510210 / 563360 / 510300 / 512100 / 159915 /
518880 / 513630 / 513500 / 159509 / 159941
```

结果：累计收益 `1304.42%`、Sharpe `0.93`、最大回撤 `-35.50%`；同期当前池约为累计 `2398.12%`、Sharpe `1.12`、最大回撤 `-25.79%`。

结论：**否决**。增加大量相关权益ETF会制造更多横截面竞争和误切换，并没有增加类似黄金那样独立的风险来源；同时该池缺少现行 `513100` 的完整历史作用。

### 2.2 用159941替换513100

结果：累计收益 `1382.73%`、Sharpe `0.92`、最大回撤 `-51.88%`。

结论：**强否决**。`513100` 是核心收益与分散贡献腿，不能用 `159941` 简单替换。

## 4. 创业板盈利后换入512890的“止盈降温”overlay

规则：

1. 当前持仓为 `159915`；
2. 从本轮入场价起累计上涨达到阈值；
3. 原策略判断下一日仍应持有创业板；
4. 下一日开盘把固定比例换入 `512890`；
5. 原策略退出创业板时同步退出该overlay。

在 2019-02-20 ～ 2023-12-31 训练期，以“不低于基准CAGR 1个百分点”为约束最大化Sharpe，选出：

```text
触发涨幅 = 3%
换入512890 = 50%
```

| 区间 | 指标 | 当前策略 | 止盈降温 |
| --- | --- | ---: | ---: |
| 训练期 | CAGR | 19.84% | **21.12%** |
| 训练期 | Sharpe | 0.903 | **0.977** |
| 样本外2024+ | CAGR | **53.79%** | 40.18% |
| 样本外2024+ | Sharpe | **1.402** | 1.323 |
| 样本外2024+ | 最大回撤 | -25.51% | -25.51% |
| 全期 | CAGR | **30.55%** | 27.35% |
| 全期 | Sharpe | 1.100 | 1.108 |

45组参数在样本外的年化收益全部低于基准。该规则降低波动，但截断了2024、2025年创业板强趋势的右尾收益，而且没有改善最大回撤。

结论：**否决，不部署**。它是降风险工具，不是收益增强或尾部回撤控制。

## 5. 511260的20日高低点阶梯策略

### 5.1 第一版：30万元资金上限，X=5万、Y=4万

从511260可用历史起，按相对20日高点下跌1%、2%、3%……阶梯买入；相对20日低点上涨1%、2%、3%……阶梯卖出。

| 指标 | 阶梯策略 | 买入持有 |
| --- | ---: | ---: |
| 累计收益 | 38.74% | 38.88% |
| CAGR | 3.93% | 3.94% |
| Sharpe | **1.59** | 1.46 |
| 最大回撤 | **-4.08%** | -4.62% |

结论：收益几乎相同，风险指标略好，但没有证明额外alpha。

### 5.2 调整版：初始总资产100万，其中50万已持有511260

买入持有对照保持50万511260、50万现金不动。三种阶梯策略：

| 版本 | 规则摘要 | 累计收益 | CAGR | Sharpe | 最大回撤 |
| --- | --- | ---: | ---: | ---: | ---: |
| 策略1 | X=5万，Y=5万 | 5.98% | 0.68% | 0.689 | -2.24% |
| 策略2 | X=5万，Y=0 | **40.79%** | **4.07%** | 1.547 | -4.62% |
| 策略3 | X=5万；上涨2%、2.5%各卖5万 | 40.52% | 4.05% | **1.584** | -4.31% |
| 买入持有 | 50万持仓、50万现金不动 | 20.00% | 2.15% | 1.501 | -2.47% |

判读：

- 策略1频繁卖出后长期持有大量现金，收益明显不足。
- 策略2/3的收益高于对照，主要因为下跌时把原本闲置的50万逐步投入，承担了更高平均仓位；这不是严格的等暴露alpha证明。
- 策略3比策略2稍浅回撤、稍高Sharpe，但差距很小。

结论：**阶梯规则可用于资金部署节奏，不应被解释为独立超额收益策略**。

### 6.2 把动量资金的50%分别换为固定ETF

已测试：

```text
511260 / 159600 / 511090 / 159397 / 512890 / 515450 / 518880
```

共同结论：

- 所有版本都降低波动或回撤；

结论：**不作为alpha增强部署**；若上层组合需要防守腿，可另做与50%现金、月度再平衡和滚动窗口的独立比较。

## 7. 债券/红利防御池及相关性

### 7.1 含黄金的防御池

```text
518880 / 511260 / 159600 / 159397 / 512890
```

动态可用池全历史：CAGR `4.45%`、Sharpe `0.373`、最大回撤 `-27.78%`，落后动态等权。

五只全部可选后的短窗口（2025-08-14 ～ 2026-07-23）：累计收益 `23.36%`，同期当前4ETF为 `24.76%`；Sharpe `1.140` 高于当前池 `0.878`，最大回撤 `-17.92%` 浅于 `-25.51%`。但窗口不足一年，且收益主要来自黄金。

### 7.2 去掉黄金

```text
511260 / 159600 / 159397 / 512890
```

2017年以来：CAGR `7.23%`、Sharpe `0.663`、最大回撤 `-14.84%`，仍落后动态等权（CAGR `8.02%`、Sharpe `1.061`、最大回撤 `-7.29%`）。

四只全部可选后的短窗口累计收益仅 `2.25%`。去掉黄金后近期收益几乎消失。

### 7.3 共同窗口的日收益相关性

2025-07-18 ～ 2026-07-23，共246个日收益：

| 资产对 | Pearson相关系数 |
| --- | ---: |
| `159600` / `159397` | 0.794 |
| `511260` / `159397` | 0.698 |
| `511260` / `159600` | 0.563 |
| `511260` / `512890` | 0.079 |
| `159397` / `512890` | 0.033 |
| `159600` / `512890` | 0.008 |

三只债券ETF形成明显的高相关簇；同时加入并不等于获得三份独立分散。`512890`是该池内主要的异质风险来源。共同历史太短，结论只作结构诊断。

结论：**防御资产直接放入Top1动量池失败；去黄金后更不具收益替代能力**。

## 9. 最终治理结论：哪些方向已关闭，哪些仍可观察

### 保留观察

1. `510500`：长历史、单独加入和消融均支持，已经进入后续5ETF研究版。
2. `159509`：全历史和2023年后的数字强，但短历史、多重测试；只做样本外跟踪。
3. `511260`或`512890`固定资金腿：仅在上层资产配置明确要求降低风险时重开，不作为主策略alpha。

### 已否决或不应重复

1. 一次性扩展到10只相关ETF。
2. 用`159941`替换`513100`。
3. 把`513500`、`588000`、`510210`、`513050`、`513180`、`512800`加入当前池。
4. 把债券ETF或红利低波直接加入Top1动量池。
5. 创业板盈利后固定比例换入`512890`的止盈降温规则。
6. 把50%主策略固定换成债券/红利ETF并宣称为收益增强。
7. 把511260阶梯策略的较高收益解释为alpha，而忽略其使用了更多闲置现金。

### 不改变现行生产参数

- 生产资产池仍以根目录changelog和生产YAML为准。
- `MOM_20 × ER_20`、Top1、T+1开盘执行、`min_hold=5`不因本文改变。
- 本文不构成新增changelog部署条目。
