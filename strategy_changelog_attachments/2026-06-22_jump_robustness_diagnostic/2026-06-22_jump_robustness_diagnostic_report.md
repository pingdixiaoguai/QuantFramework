# 单日暴跌 / 离群跳变对 score 过度敏感性诊断

- 模式：Mode C 只读诊断；未修改生产代码、生产配置、git 或实盘行为。
- 生产配置：`strategy/configs/quality_momentum_top1.yaml`（`rebalance_days=5`，默认 `min_hold`）。
- 样本：2014-01-02 至 2026-06-18（HFQ 本地价；最新共同可用交易日）。
- IS/OOS 边界：2022-09-14（2014 起交易日序列的 70% 分位；IS 含边界日）。
- EWMA：每资产独立，λ=0.94；σ_t 只使用至 r_(t-1)，初始化为上市后前 20 个有效 r² 的均值，显式剔除 EWMA 起点后的前 34 个交易日。
- Bootstrap：固定 10,000 次 percentile bootstrap（95% CI；随机种子 20260622，仅为可复现计算精度，不用于选择研究参数）。

## 停止条件与结论

**命中规模闸门（§9.1）**：至少一档 k 的崩盘相邻轮动事件 N<10。因此按预注册规则归档为“非真问题”，诊断在 Table A 后停止；未计算反事实、因变量或条件分层。

## 研究线关闭声明

“**信号估计量对单日跳变的稳健化**”（包括对 score 窗口内单日负向离群收益做 winsorize）经本诊断**关闭**，不是待实现或待参数扫描的候选改动。证据是漏斗本身稀疏：k=2.5 / 3.0 的崩盘相邻轮动事件仅为 17 / 9；严格阈值已不能达到预注册的最低 N=10。反事实中可被稳健化影响的“离群驱动”桶只是这些事件的子集，故其 N 必然不超过 17 / 9，并会更小，无法产生可解释的因变量推断。

后续不得把同一命题作为“新想法”重新提出，亦不据此改变生产信号或实盘行为。只有新的、事先注册且实质扩大事件宇宙的研究设计，才能说明为何这项关闭结论不再适用；该设计应单独立项，而不是重跑本诊断。
